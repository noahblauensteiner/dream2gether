# Space folder & session file format

A couple (or family) shares one **space**: a folder of plain files that's synced between their
devices. Any member's phone can record. The phone that records processes the night itself and
writes the result as one Markdown **session file**, with the moments plus the full transcript.

**The files are the source of truth.** Each phone's database is only an index, rebuilt from the
files. That's what makes sharing, backup and the V2 box simple: any device holding the folder
has everything.

## Space folder layout

```
dream2gether-space/
├── space.yaml                                   members, language, timezone, glossary
├── sessions/
│   └── 2026-10/
│       ├── s-2026-10-07-2250-sam.md             one file per recorded night
│       └── s-2026-10-24-2241-alex.md
├── audio/
│   └── 2026-10/
│       └── s-2026-10-07-2250-sam.m4a            full-night recording (if audio is synced)
├── photos/
│   └── 2026-10/
│       └── 2026-10-07-ramen-1.jpg
└── months/
    └── fav-moments-2026-10.md                   monthly handover file
```

- Session file names are `s-{date}-{HHmm}-{member}`. Two phones never write the same file name,
  so they never create conflicting files.
- The monthly file uses the [handover format](journal-handover-format.md). Exporting zips it with
  its photos and voice clips.

## `space.yaml`

```yaml
schema: dream2gether/space@1
name: Alex & Sam
members:
  - { id: alex, name: Alex }
  - { id: sam, name: Sam }
language: en
timezone: Europe/Vienna
glossary:                      # keeps names spelled the same in every transcript
  people: [Mila, Jonas, Grandma Rosi, Pepper]
  places: [farmers' market, boulder gym, old cinema]
```

## Session file

```markdown
---
schema: dream2gether/session@1
id: s-2026-10-07-2250-sam
recorded_by: sam
device: sams-phone
recorded_at: 2026-10-07T22:50:12+02:00
duration_s: 612
language: en
question: "What was your favourite moment today?"
audio: ../../audio/2026-10/s-2026-10-07-2250-sam.m4a
processing: { stt: whisper-small.en, llm: gemma-4-e2b, prompt: extract@1, at: 2026-10-08T03:12:40+02:00 }
---

# 🌙 Wed 7 Oct · 10 min · recorded by Sam

> *What was your favourite moment today?*

## Moments

#### 🍜 Ramen from scratch
<!-- moment: m-2026-10-07-ramen-n9qe -->
**When** Wed 7 Oct · **Where** home · **Who** both · **Tags** food, cozy · ✨ first time · ⭐ · 🔊 01:02–02:14

Six hours of broth, two burnt eggs, one perfect bowl each. We ate on the living room floor
because the table was still covered in flour.

> "Six hours for one bowl of soup and I'd do it again tomorrow."

![Two bowls of ramen on the floor](../../photos/2026-10/2026-10-07-ramen-1.jpg)

## Dreams

- 💭 Learn to make proper pho · 🔊 07:31

## Transcript

**[00:00]** Okay. Favourite moment today, go.
**[00:03]** Easy. The ramen.
**[00:05]** Six hours for one bowl of soup and I'd do it again tomorrow.
…
```

**Rules**

- **Moment blocks** use the same grammar as the [handover format](journal-handover-format.md#moment-block).
  The `🔊 mm:ss–mm:ss` part points into the session's audio.
- **Moment ids** are `m-{happened_on}-{slug}-{4 random chars}`. The random part keeps ids unique
  even when two phones create moments on the same day while offline.
- **Flags** go in the moment comment: `<!-- moment: m-… flags: edited, private -->`.
  - `edited`: changed by hand. Re-processing never touches this moment again.
  - `private`: stays in the space (both of you see it) but never goes into recaps or exports.
- **Transcript lines** are `**[mm:ss]** text`. Lines in a language other than the session's get
  a tag: `**[03:12 · nl]**`. That's ready for mixed languages later.
- **Who recorded vs. who spoke.** `recorded_by` is who pressed the button. **Who** on a moment is
  whose favourite it was; it defaults to `both` and you can edit it.

## Editing and conflicts

- **Creating** never conflicts, because each session file has a unique name.
- **Editing** happens in the app, which rewrites the file.
  - If both of you edit the same night before the phones sync, the sync tool keeps both
    versions.
  - The app spots the duplicate and asks: *"You and Sam both edited Wed 7 Oct. Keep which?"*
    It merges per moment block where it can.
- **The monthly file** is regenerated by whichever phone notices changes. A hand-edited journal
  text is always kept.
